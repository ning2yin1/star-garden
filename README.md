# 星庭パズル / Star Garden

HTML・CSS・JavaScriptのみで動く、オリジナルのマッチ3パズルです。画像・フォント・音声・外部ライブラリの取得、APIキー、ビルドは不要です。

## 起動と公開

`index.html` をブラウザで開きます。GitHub Pagesでは `index.html`、`style.css`、`engine.js`、`script.js` を同じ公開ディレクトリに置き、リポジトリの Settings → Pages でそのブランチ／ディレクトリを公開してください。ZIPを使う場合は展開してからアップロードします。

## 結晶と庭園の使命

通常ピースは紅蓮の結晶（赤）、蒼星の結晶（青）、黄金の結晶（黄）、翠風の結晶（緑）、紫月の結晶（紫）。目標は「結晶を集める」「封印石を解く」「月のかけらを集める」に統一しています。結晶・魔法・背景の画像は `images/` 内のローカル素材を使用します。公開時はこのディレクトリも配置してください。

## 操作

- クリック／タップで通常ピースを選び、隣接ピースを選んで交換。
- ドラッグ／スワイプでも交換できます。斜め移動は主要な移動方向の縦または横として扱います。
- 特殊アイテムはタップで単独発動。特殊アイテム同士の交換にはドラッグ／スワイプを使います。
- キーボード：矢印でフォーカス移動、Enter／Spaceで選択、Shift＋矢印で交換。
- 効果音ボタンでオリジナルの合成音をON／OFF。

## 実装したルール

3個以上の直線と同色2×2を検出。4直線は星の矢、2×2は風の精霊、交差した縦横3個以上（L・Tを含む）は星屑の魔法、5直線以上は虹の聖晶を作ります。同じ領域では虹の聖晶、星屑の魔法、星の矢、風の精霊の順に優先し、離れた領域ではそれぞれ生成します。生成位置は交換先、交換元、形状内の順です。生成するマスを保護して同じ消去波で消えないようにします。

星の矢は生成した直線と同方向、星屑の魔法は5×5、風の精霊は上下左右＋目標への攻撃。虹の聖晶と通常ピースの交換では交換相手の色を消去します。10種類の特殊アイテム組み合わせ、巻き込まれた特殊アイテムの連鎖、落下・補充・自動マッチを実装しています。

有効操作だけ1手消費。処理中は入力をロックし、finallyで解除します。勝敗は連鎖後に判定し、残り0手でも目標達成ならクリアです。無効交換は盤面・手数を変えません。盤面生成とシャッフルでは初期マッチがなく、有効交換があることを検証します。シャッフル時に石・特殊アイテム・月のかけらを保持します。通常ピースの並べ替えで解決できない場合は通常ピースだけ再生成します。

5ステージ、色収集・石破壊・月のかけら回収、耐久1〜3の石があります。石は固定位置で落下を区切ります。通常マッチは隣接する石に攻撃、特殊効果は効果範囲内の石に直接攻撃します。

## 設計上の独自仕様・制限

- 商用ゲームの内部仕様を完全再現したものではありません。キャラクター、ロゴ、画像、音楽のコピーはありません。
- 虹の聖晶の単独タップでは最多色を消します。最多色が同数なら色IDが小さい色を選びます。
- 風の精霊は未達成の色目標・石・月を優先し、候補内では行列順で選びます。飛行経路のアニメーションはなく、対象セルの消去演出を表示します。
- 月のかけらは特殊効果で回収するオリジナル目標です。盤面下端への落下回収は実装していません。
- 石へのダメージは1回の消去波につき最大1です。複数の特殊効果が同じ波で重なっても1ダメージとします。
- 連鎖は100波で安全停止し、安定盤面へシャッフルします。
- 進捗保存、課金、オンライン機能、商用ゲームのステージ／追加ブースターは含みません。

## 構成

- `index.html`：メイン画面。
- `style.css`：レスポンシブ表示・結晶・魔法アイテムの画像とレスポンシブ表示。
- `engine.js`：UIと分離したゲームロジック。ブラウザでは `StarGarden.Game`、Node.jsでは `require('./engine.js')`。
- `script.js`：5ステージ、入力、表示、合成効果音。
- `tests.cjs`：依存ライブラリ不要の自動テスト。

盤面サイズ・色数・手数・目標は `new Game({rows, cols, colors, moves, goals, obstacles, items})` で変更できます。ステージ設定は `script.js` の `stages` にあります。極端に小さい盤面や障害物で完全に分断した盤面では有効交換を作れずエラーになるため、遊べる設定を指定してください。
